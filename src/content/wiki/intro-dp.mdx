La Programación Dinámica (DP) es una técnica de diseño de algoritmos que consiste en resolver un problema complejo dividiéndolo en subproblemas más simples...

## ¿Qué es la Programación Dinámica?

En esencia, la DP es simplemente **recursión optimizada**. Si tienes una solución recursiva que calcula el mismo subproblema múltiples veces, puedes usar DP para guardar el resultado la primera vez que lo calculas y reutilizarlo después.

### Ejemplo: Fibonacci

La secuencia de Fibonacci se define como:
$$ F*n = F*{n-1} + F\_{n-2} $$
con casos base $F_0 = 0, F_1 = 1$.

```cpp
// Versión recursiva ineficiente
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);
}
```

Podemos optimizar esto usando **memoización**:

```cpp
// Versión con DP (Memoización)
int memo[100];
int fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib(n-1) + fib(n-2);
}
```
