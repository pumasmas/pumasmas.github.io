# Introducción a C++

C++ es el lenguaje estándar en la programación competitiva debido a su eficiencia y su potente biblioteca estándar (STL). En esta guía aprenderás los pasos básicos para empezar.

## 1. Tu primer programa

Crea un archivo llamado `hello.cpp`. El código más básico que utilizaremos sigue esta estructura:

```cpp
#include <iostream>

using namespace std;

int main() {
    cout << "¡Hola, Pu++!" << endl;
    return 0;
}
```

### Explicación rápida:

- `#include <iostream>`: Permite la entrada y salida de datos.
- `using namespace std;`: Nos ahorra escribir `std::` antes de cada comando.
- `int main()`: Es el punto de entrada de nuestro programa.

## 3. Tips para Programación Competitiva

En el club, solemos usar un "template" para agilizar la escritura y mejorar el rendimiento. Un punto clave es incluir todos los headers de una vez:

```cpp
#include <bits/stdc++.h> // Incluye casi toda la STL
using namespace std;

int main() {
    // Optimización de entrada/salida
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    // Tu lógica aquí

    return 0;
}
```
