La **Búsqueda en Profundidad** (Depth-First Search o DFS) explora lo más profundo posible a lo largo de cada rama antes de retroceder. Es la contraparte "agresiva" del BFS.

## ¿Cómo funciona?

DFS se implementa naturalmente usando una **Pila (Stack)**, o más comúnmente, mediante la **pila de llamadas del sistema (recursión)**.

### Implementación Recursiva

```cpp
vector<int> adj[1000];
bool visited[1000];

void dfs(int u) {
    visited[u] = true;
    // Procesar nodo u (ej. imprimir, contar)

    for (int v : adj[u]) {
        if (!visited[v]) {
            dfs(v);
        }
    }
}
```

## Aplicaciones

1.  **Conectividad:** Encontrar todos los nodos en una componente conexa.
2.  **Detección de Ciclos:** Si encontramos un nodo ya visitado que está actualmente en la pila de recursión.
3.  **Laberintos:** Encontrar un camino (cualquiera) de A a B.
